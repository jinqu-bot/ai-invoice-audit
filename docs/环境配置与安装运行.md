日期：2026-11-16。适用应用代码 46c8a56（PR #5 候选），不含密钥及服务器登录凭据。

## 1. 获取代码

有仓库访问权限时：

```bash
git clone https://github.com/jinqu-bot/ai-invoice-audit.git
cd ai-invoice-audit
git checkout feat/upload-invoice-reveal
```

远端功能分支可能在合并后删除，本包还提供包含历史的 Git bundle，恢复命令见“Git历史恢复说明.md”。源码 ZIP 供查看，不含 .git；不可在 ZIP 中 git init 后声称保留原仓库历史。

## 3. 本地启动

Windows PowerShell，项目根目录执行（已有 .env 时请核对，不覆盖）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
Copy-Item backend/.env.example backend/.env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

另开终端：

```powershell
cd frontend
Copy-Item .env.local.example .env.local
npm ci
npm run dev
```

打开 http://127.0.0.1:3100/upload 。`/` 为介绍页，上传无需滚过介绍动画；API 文档为 http://127.0.0.1:8000/docs 。先加载演示数据或用模拟识别验证流程，再配置真实视觉服务。

macOS/Linux 将创建命令改为 `python3 -m venv .venv`，解释器路径换成 `.venv/bin/python`，复制用 `cp`。这些平台未在本轮重新验收。

## 4. 后端环境变量

`backend/app/config.py` 自动读 `backend/.env`，真实进程环境变量优先；修改后重启后端。

| 变量 | 默认/模板 | 用途 |
| --- | --- | --- |
| DEMO_MODE | true | 演示入口开关，不等于真实模型开关 |
| CORS_ORIGINS | * | 本地跨域；部署按域名收紧 |
| UPLOAD_MAX_MB | 20 | 单张大小限制 |
| VLM_API_KEY | 空 | 私有视觉服务密钥 |
| VLM_BASE_URL | 空 | 支持图片的 OpenAI 兼容地址 |
| VLM_MODEL | qwen-vl-max | 示例默认，改为实际支持的视觉模型 |
| VLM_TIMEOUT_S | 60 | 视觉超时秒数 |
| VLM_MAX_TOKENS | 4000 | 输出 token 上限 |
| VLM_EFFORT | 空 | 可选推理档位 |
| VLM_VERIFY_HEADER | false | 抬头裁剪复核；不保证纠正所有错字 |
| VLM_FORCE_JSON | true | 请求 JSON 输出 |
| IMAGE_MAX_EDGE | 1024 | 后端送模图长边 |
| CONFIDENCE_THRESHOLD | 0.8 | 关键字段置信度阈值 |
| EXTRACT_MAX_RETRY | 1 | 校验错误回灌重试上限 |
| EXTRACT_CACHE | true | 抽取缓存，与模型/provider 核对后复用 |
| MOCK_VARIANT | 空 | 无密钥时的模拟样例选择 |
| LLM_API_KEY | 空 | 文本模型私有密钥 |
| LLM_BASE_URL | 空 | 文本模型兼容地址 |
| LLM_MODEL | deepseek-chat | 文本模型示例标识 |
| LLM_MAX_TOKENS | 2000 | 文本输出上限 |
| LLM_TIMEOUT_S | 60 | 文本超时秒数 |
| DB_PATH | 空 | 使用 backend/data/app.db，可设置绝对路径 |
| UPLOAD_DIR | 空 | 使用 backend/data/uploads，可设置绝对路径 |

缓存目录固定为 `backend/data/cache`。`MOCK_VARIANT` 可用 0、1、2、over_std、dup、header_err、non_invoice。只有视觉 key 和 base_url 均设置时才满足真实 provider 条件。健康页的 provider 不能替代单张结果的 provider/cached；模拟识别不读取票面。

## 5. 前端构建与反代

本地 `frontend/.env.local`：

```text
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8000
```

生产同源 nginx 构建时，文件中设为：

```text
NEXT_PUBLIC_API_BASE=
```

核对父进程没有相反的同名环境变量，再运行 `npm ci`、`npx tsc --noEmit`、`npm run build`、`npm run start`。API 地址构建时固化，只改配置再重启不会重写已有浏览器资源。`NEXT_PUBLIC_*` 可能进入浏览器，不能填密钥。项目没有本地自动转发 `/api` 的 rewrites，生产空值必须配套代理。

## 6. 部署与持久化

仓库提供 `deploy/nginx.conf`、两个 systemd service 和 `deploy/bootstrap.sh`。部署负责人须阅读并按路径、服务用户和环境文件调整；本轮未登录服务器、未执行 bootstrap 或清理台账。

nginx 前端转发至 3100、API 至 8000，SSE 关闭缓冲与缓存、延长读取超时。示例代理整请求上限 30 MB；每批 20 张/单张 20 MB 不等于一次允许传 400 MB。线上超限应拆批或统一调整代理与应用限制。

SQLite、上传原图和缓存不随源码分发。首次启动初始化演示结构/样例；部署目录须可写，升级前备份数据库及上传目录。`reset_demo.py` 无参数只报告；`--yes` 修改演示台账，`--flush-cache` 还清缓存。这不是评审安装步骤，不应随意对有价值的数据执行。

## 7. 不消耗模型额度的复核

```powershell
$env:PYTHONPATH='backend'
.\.venv\Scripts\python.exe -m pytest backend/tests -q
.\.venv\Scripts\python.exe backend/scripts/eval_dataset.py --as-of 2026-11-06 --mode both
```

规则评测注入 GT，不调用视觉模型。真识别脚本和真实上传可能消耗额度，需核对样本、环境与缓存口径。已存档导出及指标见 exports/ 与 verification/。

| 问题 | 检查方向 |
| --- | --- |
| GitHub 404 | 私有仓库需登录受邀账户并接受邀请 |
| API 连接失败 | 8000 服务与前端 API_BASE 本地/同源配置 |
| 上传显示固定商家 | 查看 mock-vlm 标记，不能当成识别结果 |
| 上传 413 | 代理整请求限制，核对总大小或拆批 |
| 进度一次出现 | nginx SSE 缓冲、网络与回退轮询 |
| 复测结论变化 | 基准日、台账、人工复核与缓存 |
| IP 安全连接错误 | 使用完整 http:// 地址，避免误用 https:// |
