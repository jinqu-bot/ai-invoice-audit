## 三、脚本做了什么

1. 装 `python3-venv`、`nginx`、`curl`
2. 装 **Node 20**（官方二进制包，不引第三方 apt 源）
3. 建 `aiinvoice` 用户——**不用 root 跑服务**
4. 后端建 venv、装依赖（走阿里云 PyPI 镜像）
5. 前端 `npm ci` + `npm run build`（**构建时把 `NEXT_PUBLIC_API_BASE` 设成空**）
6. 装两个 systemd 服务并设为开机自启
7. 配 nginx：`/` → 3100，`/api/` → 8000（**关缓冲，SSE 靠这个**）

### 为什么要有 nginx

前端页面里的接口地址是 `/api/*` 相对路径。没有 nginx 转发，浏览器会把 `/api/health`
当成前端页面的路径，全都 404。

而且**只有 nginx 能把 SSE 的缓冲关掉**。`proxy_buffering off` 那行删了会发生什么：
实时进度不再"每审完一张推一张"，而是攒到最后一起吐出来——"真·实时"这个卖点当场没了。

### 为什么后端必须是单进程

`--workers 1`。实时进度靠进程内的任务与事件总线（`jobs.py`），
多 worker 会出现"批次在 A 进程、查询落到 B 进程"，SSE 直接失效。

## 五、踩过的坑（部署时真实遇到的）

**依赖版本可能要求 Python ≥3.11，而 Ubuntu 22.04 自带 3.10。**

第一次部署就卡在 `pillow==13.0.0`：`Requires-Python >=3.11`，装不上。
语法层是兼容的（42 个 .py 用 3.10 语法解析全过），但**依赖的版本要求不看语法**——
这两件事得分开检查。

已把 `requirements.txt` 里 pillow 降到 `12.3.0`（本地同样的版本，测试 117 项全绿）。
`python-multipart` 之前也因为同样原因锁在 `0.0.32`。

**以后加新依赖时先看 PyPI 上的 Requires-Python**，别等部署当天才发现。

## 六、出问题怎么查

| 现象 | 八成是 | 怎么查 |
|---|---|---|
| 浏览器打不开 | 安全组没开 80 | 控制台看入方向规则 |
| 502 Bad Gateway | 后端/前端进程挂了 | `systemctl status ai-audit-backend` |
| 页面能开但数据全空 | API 基址又被写死成 127.0.0.1 | 重新 `npm run build`，确认 `NEXT_PUBLIC_API_BASE=""` |
| 进度条不动、最后一起出 | nginx 缓冲没关 | 检查 `/etc/nginx/sites-enabled/ai-audit` 里 `proxy_buffering off` |
| 上传大文件报 413 | nginx 体积限制 | `client_max_body_size 30m` |

看日志：

```bash
tail -f /var/log/ai-audit/backend.log
tail -f /var/log/ai-audit/frontend.log
tail -f /var/log/nginx/ai-audit.error.log
```

## 七、后续更新代码

改完代码重新打包上传，然后：

```bash
cd /opt/ai-invoice
tar -xzf /root/ai-invoice.tar.gz --strip-components=1   # 覆盖代码，不动 data/
sudo -u aiinvoice .venv/bin/pip install -r backend/requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
cd frontend && sudo -u aiinvoice env NEXT_PUBLIC_API_BASE="" npm run build && cd ..
systemctl restart ai-audit-backend ai-audit-frontend
```

**数据库不会丢**：`backend/data/app.db` 和 `data/uploads/` 不在代码包里，解包不会覆盖它们。

## 八、接真模型（拿到 key 之后）

```bash
cat > /opt/ai-invoice/backend/.env <<'EOF'
VLM_API_KEY=sk-xxxx
VLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VLM_MODEL=qwen-vl-max
EOF
chown aiinvoice:aiinvoice /opt/ai-invoice/backend/.env
systemctl restart ai-audit-backend
```

重启后新上传的卡片 `provider` 会变成 `openai-compat`，页面上的「演示数据」标注自动消失。
**注意：`.env` 不要进仓库。**
