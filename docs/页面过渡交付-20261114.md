## 最终行为

- 覆盖上传发票 → 审核结果 → 审核历史 → 制度问答 → 审核看板之间的站内导航，以及已有程序跳转。
- 旧页缩小、旋转退出，新页由右侧裁切展开进入，黑色过渡背景；侧栏/移动导航独立保持稳定。
- 沿用原购入动画参数：退出 1600ms，进入 1500ms、延迟 250ms，缓动 `cubic-bezier(0.65,0,0.35,1)`；没有引入新依赖或升级 Next/React。
- 保留键盘、修饰键新开链接、浏览器后退、同页输入；不支持 View Transition 或减少动态时直接导航。
- 保留最新主线的导航文字对比度修复，接口和数据口径保持原状。

## 本轮整合修复

1. **快速后退竞态**：`skipTransition()` 并不取消其更新回调。增加版本取消判断，后退/卸载后旧回调不再将用户跳回过期目标。
2. **跨页锚点**：带 hash 的链接使用 Next 原有导航，避免自定义归零逻辑破坏锚点定位。
3. **返回首页标签提前出现**：原发票地图只在 `ScrollTrigger.onUpdate` 绘制状态，进度为 0 时可能没有更新。复用原进度函数，在创建后及刷新时显式应用；首次/返回首页恢复 photo scale=0.7、flat opacity=0、12 个标签 opacity=0。20 个进度点逐值对比与原曲线一致，没有改变布局与字段坐标。

范围共 8 个前端文件：布局、导航、上传页、结果页、历史页、PageTransitions、page-transitions.css、InvoiceMapHero。冻结数据和原 verification 未改。
