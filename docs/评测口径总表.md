# 评测口径总表（答辩只认这一页）

> 2026-11-11 · A（后端）· **冻结前把数字收敛成三个，每个都有出处，其他一律作废。**

## 为什么要有这一页

到 11/11 为止，仓库里同时躺着五套数字：40 张的、58 张的、60 张的；
9 字段的、11 字段的；还有"端到端"这个一直没人重跑的。**同一件事有五个答案，等于没有答案。**
被追问一次就露馅，所以我们自己先把它们分开、标清楚、只留能站住的。

## 三个数，各有各的用途

### ① 规则口径 **60/60** —— 不是识别准确率

把 `ground_truth.json` 里的字段**原样**喂给规则引擎，量的是"规则判得对不对"。
链路里没有 OCR、没有模型。**这是规则与标注是否说同一件事，不能拿去当识别成绩。**

- 出处：`docs/对拍结果.md`（脚本生成，`python backend/scripts/eval_dataset.py --md docs/对拍结果.md`）
- 两个模式都对：独立样本 60/60、整批 60/60

### ② 识别字段（11 字段口径） **44/50 全对、544/550 字段（98.9%）**

只看"模型读出来的字段对不对"，不评结论。50 张 = 全部是发票的那些图（38 合成 + 12 实拍），
10 张非发票不进这个口径（它们单独测，见下）。

- 出处：`verification/recognition-11-fields-60.md`（脚本 `backend/scripts/evaluate_accuracy.py`）
- 分母纪律：缺失与失败**保留在分母**；GT 为空的字段必须显式标"缺失"才算对
- 分组：`real_photo` 11/12、`none`（原样）11/14、`noise` 9/10、`rotate` 8/8、`fold` 5/5、`low_confidence` 0/1

### ③ 端到端 **56/60（93.3%）** —— 唯一跑完整条链路的数

真模型读图 → 规则引擎 → 结论，和标注的 `expected_verdict` 比。
**每张票一个干净台账**（只有 3 条预置记录），避免增广样本复用母票号码时先命中 R1——
否则测出来的是查重能力，不是准确率。

- 出处：`verification/end-to-end-60.md`（脚本 `backend/scripts/eval_end_to_end.py`）
- 规则集合完全一致 54/60
- 按期望结论：pass 34/35、suspect 9/9、reject **1/3**、manual 12/13

## 四个错例，方向比数量重要

| 票 | 期望 → 实际 | 原因 |
|---|---|---|
| ds_004 | reject → **pass** | 票面印「公**可**」，模型读成「公**司**」，R3 没拦住 |
| ds_005 | reject → **pass** | 同上，同一类病 |
| real_06 | pass → suspect | 年份 6 读成 4 → 多报一次超期 → 转人工（**偏保守**） |
| ni_10 | manual → reject | 一张非发票，模型编出金额，被判驳回（**偏严**，不是放过） |

**只有前两个是危险方向**（该拦没拦），后两个都是"多问一句"。
答辩要主动这么说：**四个错里两个是危险方向，而且两个都是同一个形近字。**

> 例："60 张样本里，端到端结论一致 56 张，模型 deepseek-flash" ✅
> "我们准确率 93%" ❌

## 复跑方法

```bash
# ① 规则口径（不需要模型，几秒）
.venv\Scripts\python.exe backend\scripts\eval_dataset.py --md docs\对拍结果.md

# ② 11 字段（要能连到线上后端）
.venv\Scripts\python.exe backend\scripts\evaluate_accuracy.py --files <文件名...> \
    --base http://8.217.202.172 --output verification\recognition-11-fields-60.md

# ③ 端到端（要有模型 key，在服务器上跑）
cd /opt/ai-invoice/backend && /opt/ai-invoice/.venv/bin/python scripts/eval_end_to_end.py \
    --json /root/e2e.json --md /root/e2e.md
```

> 注意 ③ 会读识别缓存：同一张图第二次跑是毫秒级（报告里会写"缓存命中 N 张"）。
> 想量真实耗时，先 `reset_demo.py --yes --flush-cache`。
