# 真模型那条路，我用一个本地桩验过了

> A（后端）· 2026-11-07 · 起因：队长拿真发票测试，页面给出的是 mock 的假数据

## 一句话

**没有真模型 key，但"接真模型"这段代码已经被真跑过了。**
我用一个本地假模型（`_local/fake_vlm.py`）冒充 OpenAI 兼容接口，
让后端走完整的 `provider=openai-compat` 路径，
确认了请求格式、图片编码、JSON 解析、超时重试、下游规则全都对得上。

这件事很重要：之前所有测试走的都是 mock，而 **mock 根本不读图片**——
等于这段代码一行都没被执行过。等比赛前拿到 key 才第一次跑，出了错来不及改。

---

## 验证到了什么

### 1. 请求是真的带着图片出去的

抓到的实际请求（`_local/fake_vlm_last_request.json`）：

```
model            : qwen-vl-max
temperature      : 0
response_format  : {"type": "json_object"}
messages[0]      : system，1032 字（发票字段说明 + 输出格式约束）
messages[1]      : [ text(28字), image_url ]
image_url        : data:image/jpeg;base64,/9j/4AAQ…  共 41547 字符
```

那张 353KB 的真发票，压缩之后以 **base64 data-URI** 塞进了 `image_url`，
不是文件名、不是本地路径——**换个 OpenAI 兼容的供应商，这段不用改。**

### 2. 回包解析、置信度、规则全都接上了

桩返回的字段就是队长那张票的真实内容（笔记本 ¥4748、抬头「戴海青」、开票 2026-08-15）：

```
provider : openai-compat / qwen-vl-max
金额     : 4748.0
购买方   : 戴海青
日期     : 2026-08-15 · 类目 办公 · 税率 13%
verdict  : reject
命中     : R0 置信度不足 30%（购买方税号为空）、R3 抬头不符、R4 超期 84 天
```

**这张票本来就该被驳回**：抬头是个人不是公司（R3），而且开票到今天 84 天（R4）。
跟 mock 给出的"重复报销"完全是两回事——**这说明结论的可靠性完全取决于识别，
识别是假的，后面的规则再对也没意义。**

### 3. 顺手验证了置信度逻辑对"缺字段"的处理

`compute_confidence` 取的是**关键字段里最没把握的那个**（不是平均）。
购买方税号为空 → 该项 0.30 → 整体 0.30 → 触发 R0 转人工。
这是对的：个人抬头的票本来就没有税号，机器"读不到"和"确实没有"分不清，
就该转人工看一眼，而不是硬猜。

## 复现方式

```powershell
# 1. 起假模型（8001）
.venv\Scripts\python.exe _local\fake_vlm.py

# 2. 起后端并指向它（8002），显式给 key 让它走真路径
$env:VLM_API_KEY="test-key"
$env:VLM_BASE_URL="http://127.0.0.1:8001/v1"
$env:VLM_MODEL="qwen-vl-max"
.venv\Scripts\python.exe -m uvicorn app.main:app --port 8002
```

然后正常上传一张图，`provider` 会显示 `openai-compat`，不再有「演示数据」标注。

## 换成真 key 只差三行环境变量

`.env` 里填上（`backend/.env.example` 已有模板）：

```
VLM_API_KEY=sk-xxxx
VLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VLM_MODEL=qwen-vl-max
```

`settings.configured` 一看 key 和 base_url 都非空，就自动从 mock 切到真模型，
**代码零改动**。通义千问 VL、DeepSeek-VL、任何 OpenAI 兼容的多模态接口都能接。

---

## 这段验证不能替代什么

桩不认图，它固定回一张票的字段。所以它证明的是**管道通**，
不证明**模型认得准**。真正的识别准确率，只有拿到 key 跑真图才知道。

答辩时如果被问"你们接了真模型吗"，准确的说法是：

> 识别模块按 OpenAI 兼容协议写好了，请求里带的是压缩后的 base64 图片，
> 整条链路用本地桩验证通过；**真模型还没接（没有 key），
> 所以现在页面上的数字是演示样例，界面上有明确标注。**

不吹、不藏。把"管道通了"和"模型能认出票"分开说，比含糊其辞可信得多。
