## 六、破坏性演练（**这一轮最值钱，别跳**）

正常演一遍只证明"顺利时能演"。下面 7 个故障，一个一个注进去，看主讲人接不接得住。

| # | 怎么造 | 期望表现 | 主讲人该说什么 | 过了吗 |
|---|---|---|---|---|
| 1 | 上传时**拔网线 / 关 Wi-Fi** | 批次失败，`failures` 里写清原因，页面不白屏 | "现在模型调不通，我不演实时识别了，用固定数据继续" | |
| 2 | 上传一个**坏的 jpg**（把 txt 改名成 .jpg） | 显示文件名 + `BAD_IMAGE`，**不是整批挂掉** | "坏文件单独列出来了，其余照常审" | |
| 3 | 连传**两张同一张票** | 第二张先命中 R1 并短路 | "这是重复报销，查重第一条就拦住了，后面不再查" | |
| 4 | 复核时**不勾选**"已核对原图"就提交 | 被拦住，有提示 | "我们不让人随手改判，必须先核过原图" | |
| 5 | `/ask` 问一个**制度里没有**的问题（如"年会抽奖怎么报"） | 明确答"制度里没有相关条款" | "它不会编。这是最该看的一条" | |
| 6 | 详情页点「让 AI 自己决定先查什么」，**同时**把服务器 key 改坏 | 返回 503 / 502，页面给提示 | "现在没接真模型，这一步不演" | |
| 7 | 结果页**按 F5 刷新**（SSE 断） | 结果还在（走 `/results` 兜底） | "流断了不影响结论，后端已经存下来了" | |

> 第 6 条改完记得**改回来**，不然正式演示时模型是坏的。
> 每一条失败都记下来：是系统的锅，还是主讲人接不住？**两种都要修，修法不同。**

## 七、复盘（15 分钟，别边演边改）

回答四个问题，写下来：

1. **超时了吗？** 超了几秒？砍哪句话最不心疼？
2. **哪一幕最冷？** 冷在等结果，还是在找按钮，还是在念台词？
3. **七个故障里，哪几个主讲人卡住了？** 具体卡在哪句话。
4. **录像能提交吗？** 听不清？画面糊？露出隐私？

**然后只改这三类**：① 台词太长（砍）② 操作顺序不顺（调）③ 故障话术没有（补）。
**不改功能、不改代码**——今天不是写代码的日子。

## 十、提交版录像的三个合规点（这条别忽略）

1. **那张真发票上有第三方的姓名和税号**（本文档统一用占位名「臧海涛」代替）。
   现场答辩口头讲没问题，但**提交的视频是公开材料**，把别人的姓名税号录进去不合适。
   > **已经有替代品了**：`backend/data/demo/demo_personal.jpg`
   > —— 我们自己生成的"个人抬头 + 超期"样票，购买方写的是「个人用户」（编的），没有税号。
   > 线上实测命中 **R3 + R4，结论 reject**，和真票的叙事完全一样，金额也是 4748，台词不用改。
   >
   > 生成命令：`python backend/scripts/make_demo_invoice.py`
   >
   > **用法**：现场答辩用真票（有冲击力），**提交的录像用这张样票**。
   > 如果被问"这是真票吗"，答："录像里这张是我们自己做的样票，因为真票上有别人的姓名税号，
   > 不适合放进公开视频；现场这张是真票，你可以看。"
   > —— 这个回答本身就是加分项。
2. **不要说"已完成真实报销审批"**。系统做的是审核建议 + 留痕，不是付款。
3. **改判理由不许写"已补开发票、财务确认"**。没这回事。用"联调测试：验证改判留痕，不代表真实报销审批"。
