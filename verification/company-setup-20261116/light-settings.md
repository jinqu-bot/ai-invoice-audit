# 公司配置浅色页面与导航调整

2026-11-16，基于 `main@16d95e6`。按照用户提供的审核看板截图，将独立 `/settings` 页面改为浅灰白背景、白色表单卡片与输入框、深色文字、蓝色按钮；桌面侧栏和手机导航共用的菜单删除“公司配置”，恢复六项。

- 桌面导航六项，无公司配置链接。
- 校验错误、保存成功提示、加载失败与重试均可见可用。
- 手机表单无横向溢出，横向导航可滑到第六项审核看板。
- 上传页仍为深色，上传前配置限制和整页入场结束状态正常，只有一个动画实例。
- 上述五组浏览器检查全部通过，无页面异常；见 [light-settings-check.json](light-settings-check.json)。
- 同源 API 配置下 `npm run build` 退出码 0（含类型检查），`git diff --check` 通过。
